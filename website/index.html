Workspace Tools

Bring Your Own Key

Export & Beautify

Slash Commands

AI Agent

Your AI writes, refactors, and edits — with real tool calls.

MEditor ships with a full AI Agent, not just a chat panel. It reads your document, calls tools to patch specific sections, searches your workspace — and shows every step transparently.

  • Multi-turn reasoning loop that runs to completion
  • Document tools: read, write, patch, insert with precision
  • Workspace-confined writes & risk-graded shell commands — every risky action needs your approval
  • Visual Diff Review for AI-proposed changes before you accept
  • Slash commands & a selection floating bar — rewrite, tighten, expand, translate without leaving the editor
  • Current document auto-attaches as context, smartly trimmed around your cursor when budgets get tight
  • Diagnostics with one-click "Let Agent fix it" — the model repairs, then re-scans so you can compare
  • OpenAI & Anthropic SSE streaming, plus Claude CLI backend
  • Skill system — built-in + an extensible gallery
Editor

A real editor. Not an afterthought.

Syntax highlighting for 40+ languages, bidirectional scroll sync with anti-loop protection, native find & replace with jump-to-line, and a fuzzy file finder (⌘P) — everything you'd expect from a desktop app.

  • Live Markdown preview with Mermaid diagram support
  • Presentation mode — turn any document into slides
  • Focus mode for distraction-free writing
  • Global search across the workspace (⌘⇧F)
  • Copy as rich text (⌥⌘C) — paste into email or Feishu with formatting intact
  • Todo inbox with calendar & week timeline views
  • Document templates for recurring note types
  • Tabs: drag to reorder, reopen closed, right-click for close-others / reveal in Finder / save as template
  • GitHub, Nord, and Dracula themes
  • Automatic updates — new versions install themselves
