Why 13.5 MB matters

One native binary. Not a browser in a window.

The Electron apps in this table bundle an entire Chromium runtime and Node.js — which is why they launch slower, use more memory, and feel like a web page wearing a window frame.

  • Real NSTextView editing — native find & replace, text services, and undo, not a JavaScript reimplementation
  • Instant launch; no runtime to unpack, no renderer process per tab
  • Quick Look previews from Finder and Spotlight indexing — the OS knows your documents
  • Works fully offline; your documents and API keys never leave the machine
Boundaries

What MEditor
doesn't do (yet).

A comparison page that only lists wins isn't a comparison. Here is what we don't have:

  • No vault graph or backlinks. If you live in a knowledge graph, Obsidian remains the better tool — MEditor is a document workstation, not a second brain.
  • No Windows or Linux build. macOS and iOS only, native on both.
  • The release build isn't notarized. First launch takes a right-click → Open. Developer-ID signing and notarization are planned.
  • Pro publishing is early access. The editor itself is free and unrestricted; Pro only lifts the hosted-publishing limits.
