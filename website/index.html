Built for writers who
think in Markdown.

Every feature — from live preview to workspace tools — is designed to stay out of your way and let you focus on writing.

Built-in AI Agent
Multi-turn reasoning loop. The Agent reads your document, calls tools, sees results, and keeps going until the task is done — all inline.
Real-time Preview
Editor and preview scroll in sync. Code blocks and Mermaid diagrams render instantly as you type.
Workspace Tools
List files, search across your vault, open tabs, run sandboxed shell commands — all accessible to the AI Agent.
Streaming Output
Responses appear word-by-word. Tool steps show inline with expand/collapse detail — you always know what the Agent is doing.
Bring Your Own Key
9 provider presets out of the box — OpenAI, Anthropic, DeepSeek, Kimi, GLM, Qwen, OpenRouter, Groq, Ollama. Already use Claude Code? The local CLI backend reuses your existing login — zero configuration. Any OpenAI-compatible endpoint works.
Export & Beautify
Export to HTML, PDF, or 2× PNG in one click — themed PDFs with clickable links, and a pre-flight check that catches dead links and missing images first.
Slash Commands
Type / anywhere — /polish, /outline, /translate, /table. Commands that rewrite your document stream a diff you confirm before it lands.
Local History
Every save keeps a snapshot, no setup required. Diff any two versions and restore in one click — the restore itself is undoable.
Images Auto-save
Paste a screenshot or drag an image in — it's written to assets/ and inserted as a clean relative path. No more broken image links.
LAN Sharing
Built-in HTTP server with one-time token auth. Share your document over Wi-Fi instantly.
MCP Server — your workspace, drivable from outside
MEditor ships a built-in MCP server over stdio, so Claude Desktop, Cursor, or any MCP client can read, write, patch and search your workspace through the same 11 tools the in-app Agent uses — no editor window required. Shell commands stay off by default. One line in your client config: 
{ "mcpServers": { "meditor": { "command": "/Applications/MEditor.app/Contents/MacOS/MEditor",
    "args": ["mcp", "--workspace", "/path/to/your/workspace"] } } }
AI Agent

Your AI writes, refactors, and edits — with real tool calls.

MEditor ships with a full AI Agent, not just a chat panel. It reads your document, calls tools to patch specific sections, searches your workspace — and shows every step transparently.

  • Multi-turn reasoning loop that runs to completion
  • Document tools: read, write, patch, insert with precision
  • Workspace-confined writes & risk-graded shell commands — every risky action needs your approval
  • Visual Diff Review for AI-proposed changes before you accept
  • Slash commands & a selection floating bar — rewrite, tighten, expand, translate without leaving the editor
  • Current document auto-attaches as context, smartly trimmed around your cursor when budgets get tight
  • Diagnostics with one-click "Let Agent fix it" — the model repairs, then re-scans so you can compare
  • OpenAI & Anthropic SSE streaming, plus Claude CLI backend
  • Skill system — built-in + an extensible gallery
Trust

An Agent that
asks before it acts.

An agent with write access to your files earns trust the old-fashioned way: it asks first, shows its work, and can be undone.

Write confirmation
The Agent asks before it writes any file. Mid-flow? “Allow all for this run” skips the prompts without skipping the review.
Risk-tiered sandbox
Shell commands are classified by risk before they run. Blocked commands are always rejected; risky ones wait for your approval.
Diff review by default
AI edits land as reviewable diffs — they never clobber what you're typing. Accept, reject, or keep editing.
Run-level rollback
Every Agent run leaves checkpoints. Changed your mind? One click restores the whole run — and the restore itself is undoable.
Budgets & stall detection
A token budget with automatic eviction keeps long sessions on track; runaway loops are stopped, not tolerated.
Fully observable runs
Token usage and elapsed time for every run, every tool step expandable — you see exactly what the Agent did, and what it cost.
Stability

Actively built.
Honestly versioned.

Every release ships with a CHANGELOG entry, Ed25519-signed in-app updates via Sparkle, and MIT source you can build yourself. Still pre-1.0: we follow semantic versioning and call out breaking changes in the CHANGELOG — there have been none so far. 1.0 arrives when today's feature set has shipped stable for a full release cycle — no date promised, no features held back.

Editor

A real editor. Not an afterthought.

Syntax highlighting for 40+ languages, bidirectional scroll sync with anti-loop protection, native find & replace with jump-to-line, and a fuzzy file finder (⌘P) — everything you'd expect from a desktop app.

  • Live Markdown preview with Mermaid diagram support
  • Presentation mode — turn any document into slides
  • Focus mode for distraction-free writing
  • Global search across the workspace (⌘⇧F)
  • Copy as rich text (⌥⌘C) — paste into email or Feishu with formatting intact
  • Todo inbox with calendar & week timeline views
  • Document templates for recurring note types
  • Tabs: drag to reorder, reopen closed, right-click for close-others / reveal in Finder / save as template
  • GitHub, Nord, and Dracula themes
  • Automatic updates — new versions install themselves
